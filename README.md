A lightweight Windows app that syncs **Spotify playback + real-time lyrics** to your Discord Rich Presence.

## Download

Latest release:  
[https://github.com/miiiwdy/SpotifyLyricsRPC/releases/tag/v1.0.0](https://github.com/miiiwdy/SpotifyLyricsRPC/releases/tag/v1.0.1)

Download:
- `SpotifyLyricsRPC.exe`

---

## How to Use

### 1. Run the app
Double click:
- `SpotifyLyricsRPC.exe`

### 2. First time setup
If this is your first time running it, you will be asked:

- `Paste your Discord Application ID`

It will be saved automatically into config.json

---

### Requires Spotify Desktop App
### Requires Discord Desktop App running
